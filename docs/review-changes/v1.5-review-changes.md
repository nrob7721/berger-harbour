# Bugs

1. Customer gets to summary, clicks Your Details to change Mobile, enters incorrect mobile and then clicks Choose Boat and Dates or Back. Invalid mobile number is wiped. Expected: invalid mobile kept until customer advances and validation stops them on the Your Details page again.
1. DONE An expired booking must be editable. If the dates were taken by another booking, the user can't add a manual payment and also can't change the dates. Solution: Enable all fields when the first payment is added even if it isn't saved
1. A new booking Schedule can show the balance as due before the creation date. We need extra logic that if a booking is created within expected milestones, the schedule shows them as due immediately on the date of creation instead of 1 week before creation
1. New booking process - Midweek selected by staff erroneously, staff adds an addon, default price for Midweek given. Staff change booking type to Week, the addon price remains that of the Midweek setting. Ideally, if the addon price has not been set by staff manually, it should follow the booking type.
1. Changing the booking type or boat on a new booking is not changing the Hire Price or addons. On existing bookings, they should be set and saved to the booking however, for brand new bookings that haven't been saved, changing the type of booking should affect hire price and addon default prices. Changing the boat should affect the hire price.
