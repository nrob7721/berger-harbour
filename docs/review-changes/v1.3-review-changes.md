# Changes

1. Address field - this data will eventually be used to populate an address on a hire agreement. Instead of a large free text field, We want individual fields for Address Line 1, Address Line 2, City/Locality, State, Post Code, Country
1. Hold functionality - When a customer has not completed the deposit payment, the booking exists with status PendingPayment and is visible in admin but it is not editable. Presumably this is to avoid the admin using changing the price or addons while the stripe payment link is still active. It then falls into status Expired. However, the staff may contact the customer to confirm the booking. In this scenario, we want them to be able to reactivate the booking
    1. Pending Payment - all customer fields disabled as the customer might still pay through the gateway. Save button should also be disabled
    1. Expired - the "Make manual payment" button becomes active again. When the staff add a manual payment for the deposit amount or higher, fields should be editable and status becomes active. There is already a Bookings.ActivateFromDeposit() method, we just want this called from the admin side as well
    1. Confirm: can the customer still make a stripe payment while the booking is in status Expired? Ideally, the stripe payment availability should expire when the booking goes into status Expired.
